# improve-performance

Applies when: a measured slowness to improve against a baseline.

1-measure-baseline: Measure a baseline with run count and spread before any change. (diagnose, explain-measurements)
2-name-limiter: Name the limiting resource with profiling evidence. (explain-measurements)
3-change-one-thing: Change one thing at a time and remeasure. (implement, sequence-verifiable-units)
4-explain-the-gain: Explain the gain and why it is not larger. (explain-measurements)
5-verify-behavior-unchanged: Show behavior is unchanged on the real surface, with the project's verification skill when one exists. (verify-on-real-surface)
6-update-obsolete-docs: Update documentation this change makes obsolete. (implement)
7-publish-draft-pr: Push the final commits and update the draft PR when publication is authorized. (ship-pr)

Reply: baseline, result, spread, and limiter.
