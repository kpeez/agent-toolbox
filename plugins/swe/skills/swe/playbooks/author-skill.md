# author-skill

Applies when: write or edit a skill, `AGENTS.md`, or `CLAUDE.md`.

1-read-writing-doctrine: Load the writing-for-agents doctrine and its skill mechanics. (writing-for-agents)
2-choose-invocation: Choose model-invoked, model-only, or user-invoked and say why. (writing-for-agents)
3-single-source-check: Point to the existing home of any rule instead of restating it. (writing-for-agents)
4-check-packaging: Check version parity, catalog entries, resource links, and a NOTICE for adapted content, as the repository's AGENTS.md requires.
5-run-validators: Run the verification checks that the repository's AGENTS.md names for the changed files.
6-plan-activation-check: When a model-invoked description changes, add or update an activation case. (evaluate-agent-change)
7-publish-draft-pr: Push the final commits and update the draft PR when publication is authorized. (ship-pr)

Reply: the change, its always-on character cost, and the checks run.
