# author-skill

Applies when: write or edit a skill, `AGENTS.md`, or `CLAUDE.md`.

1-choose-invocation: Choose model-invoked, model-only, or user-invoked and say why. (writing-for-agents)
2-single-source-check: Point to the existing home of any rule instead of restating it. (writing-for-agents)
3-check-packaging: Apply the packaging rules and run the checks that the repository's AGENTS.md names for the changed files.
4-plan-activation-check: When a model-invoked description changes, add or update an activation case. (evaluate-agent-change)
5-publish-draft-pr: Push the final commits and update the draft PR when publication is authorized. (ship-pr)

Reply: the change, its always-on character cost, and the checks run.
