# appraise-source

Applies when: one paper, preprint, blog post, model card, or result to judge.

You own the verdict on each claim. Read, check, and grade. Do not defend or attack the source.

The work is read-only. It writes no memo file unless the user asks for one. Judge the source from its own evidence and from what others found after it. For many sources on one question, use review-literature. For your own results, use analyze-results.

1-get-the-original: Open the latest version with its appendix, code, and data, and record the version you read. Check the Source section. (claim-checklist)
2-extract-claims: List each central claim with the table or figure offered for it, and write each claim at the scope its evidence supports. Check the Scope section. (claim-checklist)
3-check-comparisons: For each "A beats B" claim, confirm that both sides got the same data, compute, and tuning, and that an ablation isolates the credited part. Check the Comparison section. (claim-checklist)
4-check-noise: For each number behind a claim, find the run count, the spread, and the noise floor, or note that the source gives none. Check the Noise section. (claim-checklist)
5-list-rivals: For each claim, list the other explanations, such as leakage, contamination, a metric artifact, or a confound, and mark each as ruled out or open. Check the Rivals section. (claim-checklist)
6-read-examples: Read the qualitative examples and any released data or outputs, and note each case that fits or breaks a claim. Check the Raw data section. (claim-checklist)
7-search-follow-ups: Search forward citations, replications, critiques, and public reviews, and record what each finds for each claim. Check the Contrary evidence section. (claim-checklist)
8-grade-each-claim: Give each claim one grade from the strength and independence of its evidence. (grade-the-evidence)
9-feed-the-flywheel: Ask whether this run repeated a procedure or drew a user correction. If yes, propose or update a project skill, and name it in the reply. (encode-the-procedure)

Reply: for each claim, the claim as stated, the claim as supported, its grade, and its main weakness; then what evidence would change the verdict, and any project skill proposed or updated.
