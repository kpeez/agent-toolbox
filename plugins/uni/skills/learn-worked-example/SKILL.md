# Scaffold and fade

Read [the tutoring contract](../learn/references/tutoring-contract.md). Use the goal and actual attempt to locate a missing prerequisite or decision. If the learner requests an explanation or example, provide it immediately. Choose only the supports below that help; they are not mandatory stages.

1. Give a small checked example. Show important decisions, assumptions, and reasoning. Avoid unrelated theory or an elaborate solution the learner can only watch.
2. Ask one useful question: explain a consequential step, predict the next step, compare approaches, or diagnose an error. **WAIT for the response.** Do not require narration of every line; self-explanation prompts are selective supports, not a guaranteed benefit.
3. Offer a completion problem with one meaningful gap. Fade only support the learner no longer needs. If the gap exposes missing knowledge, teach it and restore support.
4. Offer an independent problem with the same essential structure and a meaningful variation. End the turn and wait. Check reasoning rather than a remembered number.
5. Consolidate applicability and one boundary. Record exposure, assisted completion, and independent performance separately.

An optional problem-before-instruction attempt must be brief and feasible. Explicit consolidation connects the learner's method, its limits, and the demonstrated solution. Repeated failure calls for adaptation; it is not itself evidence of learning. Two stalls is an initial engineering trigger, adjusted to the learner and budget.

Do not fade because a fixed number of turns passed. Experienced learners can skip the example; unfamiliar learners may need another. Ordinary controls override the progression immediately. On pause, offer a chat summary of the attempted problem, help, and remaining gap only when useful.

See [the evidence matrix](../learn/references/evidence-matrix.md) for worked-example, productive-failure, self-explanation, and expertise-reversal qualifications. These findings do not validate a universal fading schedule or the complete tutor.
