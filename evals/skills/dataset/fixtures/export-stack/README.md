Invoice export for the tally billing service. Amounts are integer cents.

This folder is a copy of the working tree of `export/out-flag`, the top branch of a stack of three pull requests. The copy has no git history, no remote, and no access to the forge. `stack.md` holds each PR's state as the forge reported it, `checks.log` holds the CI runs for each head, and `pr-41.diff`, `pr-42.diff`, and `pr-43.diff` hold each PR's patch against its base.
