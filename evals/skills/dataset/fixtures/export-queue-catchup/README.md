Invoice export for the tally billing service. Amounts are integer cents.

This folder is a copy of the main checkout. It has no git history, no remote, and no access to the forge. `commits.txt` holds `git log` for `main` and the open branches since 2026-11-12, `prs.md` holds each pull request's state as the forge reported it on 2026-11-16, and `decisions.md` is the decision log of the run that worked on the queue.
